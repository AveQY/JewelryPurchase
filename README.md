# 珠宝购 - JewelryPurchase 客户端

## 项目简介

JewelryPurchase 是 **珠宝购** 交易平台的安卓项目，主要软件前端展示，以及软件交互。

## 开发工具

AndroidStudio + Git

## 技术栈

- Java
- Retrofit
- XML + ViewBinding
- OkHttp + Gson + Glide
- Gradle + Kotlin DSL

## 快速开始

#### 线下调试

在项目 `app/src/main/java/com/example/jewelrypurchase/jpWeb/WebUrl` 的`getBASE_URL `方法中修改 **return** 值。

**注意！提前部署好本地后端服务，才能正常运行，否则，请勿修改任何内容**

#### 线上调试

无须修改任何内容
